## Задание 1. Функции и ссылки

Перед запуском были сформулированы прогнозы для шести экспериментов, затем они были проверены запуском файла `examples/functions-and-references.js`. В эксперименте 2 в исходном файле отсутствовал `return`, из-за чего функция возвращала `undefined`. Этот недостаток был исправлен.

| № | Прогноз | Фактический результат | Причина |
|---|---|---|---|
| 1 | `5` и `"23"` | `5` и `"23"` | Оператор `+` со строкой выполняет конкатенацию, а не сложение |
| 2 | `16` (после исправления) | `16` | В исходном виде тело `{}` без `return` давало `undefined`; после добавления `return` работает корректно |
| 3 | `true`, `true` | `true`, `true` | Объекты — ссылочный тип: `alias` и `original` указывают на один и тот же объект |
| 4 | `"Изменённая книга"`, `false` | `"Изменённая книга"`, `false` | `[...books]` копирует только верхний уровень массива; объекты внутри остаются теми же ссылками |
| 5 | `false`, `true` | `false`, `true` | Spread объекта создаёт поверхностную копию, повторное свойство перезаписывает предыдущее |
| 6 | `"Без названия"`, `"Без названия"`, `null` | `"Без названия"`, `"Без названия"`, `null` | Значение по умолчанию срабатывает только для `undefined`; `null` — валидное значение, подстановки нет |

Вывод: `[...array]` и `{ ...object }` выполняют **поверхностное** копирование; вложенные объекты остаются общими. Для их независимого изменения нужно копировать каждый объект отдельно.

## Задание 2. Создание задачи (`createTask`)

Функция возвращает `{ ok: true, task }` при успехе и `{ ok: false, error }` при ошибке.

| Вход | Результат | Комментарий |
|---|---|---|
| `createTask(20, "Новая задача", "high")` | ok, задача создана | Базовый корректный случай |
| `createTask(1, "Задача")` | ok, `priority = "medium"` | Значение по умолчанию |
| `createTask(1, " Проверить данные ")` | ok, `title = "Проверить данные"` | Название нормализовано |
| `createTask(0, "x")` | error | `id` должен быть > 0 |
| `createTask(-1, "x")` | error | Отрицательный `id` |
| `createTask(1.5, "x")` | error | `id` не целый |
| `createTask("4", "x")` | error | `id` не число |
| `createTask(NaN, "x")` | error | `NaN` не безопасное целое |
| `createTask(Infinity, "x")` | error | `Infinity` не безопасное целое |
| `createTask(null, "x")` | error | `null` не число |
| `createTask(Number.MAX_SAFE_INTEGER + 1, "x")` | error | За пределами безопасных целых |
| `createTask(1, "")` | error | Пустое название |
| `createTask(1, "   ")` | error | Только пробелы |
| `createTask(1, "a".repeat(101))` | error | Длиннее 100 символов |
| `createTask(1, 42)` | error | Название не строка |
| `createTask(1, null)` | error | Название не строка |
| `createTask(1, "x", "urgent")` | error | Недопустимый приоритет |
| `createTask(1, "x", "HIGH")` | error | Регистр важен |
| `createTask(1, "x", " high ")` | error | Пробелы не допускаются |
| `createTask(1, "x", 1)` | error | Приоритет не строка |

## Задание 4. Изменение данных без мутации

| Операция | Результат | Исходный массив |
|---|---|---|
| `addTask(demoTasks, 20, "Подготовить демонстрацию", "high")` | ok, длина 5 | длина 4, не изменён |
| `addTask([], 1, "Первая")` | ok, массив из 1 элемента | — |
| `addTask(demoTasks, 4, "Дубликат")` | error: `id` уже существует | не изменён |
| `setTaskCompleted(demoTasks, 4, true)` | ok, `completed = true` у id 4 | остальные задачи не изменены |
| `setTaskCompleted(demoTasks, 999, true)` | error: задача не найдена | не изменён |
| `setTaskCompleted(demoTasks, 4, "yes")` | error: `completed` не boolean | не изменён |
| `renameTask(demoTasks, 10, "  Обновлённое README  ")` | ok, `title = "Обновлённое README"` | не изменён |
| `renameTask(demoTasks, 10, "a".repeat(101))` | error: длиннее 100 символов | не изменён |
| `renameTask(demoTasks, 999, "x")` | error: задача не найдена | не изменён |
| `removeTask(demoTasks, 7)` | ok, id `[1, 4, 10]` | не изменён |

Вывод: все функции возвращают **новый** массив; исходный `demoTasks` остаётся неизменным. Изменение отдельного объекта (`{ ...task, completed }`) тоже создаёт копию, а не мутирует оригинал.
