## Задание 4. Чистая валидация формы

`validateTaskDraft` не обращается к DOM и не показывает сообщения. Возвращает `{ ok: true, value }` или `{ ok: false, errors }`.

| Поле | Правило | Проверено |
|---|---|---|
| id | После `Number` — положительное безопасное целое, нет дубликата | 0, -1, 1.5, "4", пустая строка, существующий id |
| title | Строка, после `trim` от 1 до 100 символов | Пустая строка, пробелы, 101 символ, число |
| priority | Строго low, medium, high | "urgent", "HIGH", null, 1 |

В режиме редактирования id берётся из `editingId`. Совпадение с самой редактируемой задачей не считается дубликатом.

## Задание 5. Модуль локального хранения

Реализованы `isValidTaskList`, `loadTasks`, `saveTasks`, `removeSavedTasks`.

| Функция | Контракт | Проверено |
|---|---|---|
| `isValidTaskList` | Проверяет весь массив и уникальность id | Корректный, повторяющийся id, неверные поля |
| `loadTasks` | `initial` / `storage` / `fallback` | Отсутствие ключа, корректные данные, повреждённый JSON |
| `saveTasks` | Записывает `{ version: 1, tasks }` | Корректный и некорректный список |
| `removeSavedTasks` | Удаляет ровно один ключ | Успех и исключение |

Формат записи: `{"version":1,"tasks":[...]}`. Версия проверяется при чтении. При повреждённых данных возвращается исходный набор и предупреждение.

## Задание 6. Форма создания и редактирования

`setFormMode(null)` включает поле id, очищает форму, устанавливает заголовок «Добавление задачи», подпись кнопки «Добавить задачу», скрывает кнопку отмены и переводит фокус в поле id.

`setFormMode(id)` находит задачу, заполняет поля, блокирует id, меняет заголовок на «Редактирование задачи», подпись кнопки на «Сохранить изменения», показывает кнопку отмены и переводит фокус в поле названия.

`handleFormSubmit` вызывает `preventDefault()`, читает поля через `FormData`, передаёт черновик в `validateTaskDraft`, при успехе вызывает `addTask` или `updateTask`, сохраняет результат и возвращает форму в режим создания.

## Задание 7. Интеграция действий и хранения

| Действие | Результат | Запись в storage |
|---|---|---|

| `toggle` | Изменение `completed`, отрисовка | Да |
| `delete` | Удаление, отрисовка | Да |

Кнопка сброса вызывает `removeSavedTasks` только для текущего `storageKey`, восстанавливает копию `initialTasks`, возвращает фильтр `all` и форму создания, обновляет интерфейс.
